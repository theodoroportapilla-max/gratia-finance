# Gratia Finance

**Personal Finance Management Platform**

O Gratia Finance é uma plataforma de gerenciamento financeiro pessoal desenvolvida para permitir que usuários organizem suas receitas, despesas, contas e metas financeiras em um único ambiente.

Inspirado no conceito de organização e planejamento, o projeto busca oferecer uma experiência intuitiva, moderna e acessível, facilitando o acompanhamento da vida financeira e auxiliando na tomada de decisões.

## 🎯 Objetivo

Desenvolver uma solução completa de controle financeiro pessoal, oferecendo recursos para registrar movimentações, acompanhar gastos, organizar contas, estabelecer metas e visualizar a evolução financeira de maneira simples e eficiente.

## 🏗️ Arquitetura

O projeto será organizado em módulos independentes, permitindo a evolução da plataforma Web e a futura integração com uma aplicação Mobile.

```text
gratia-finance/
├── web/          # Plataforma Web
├── mobile/       # Aplicativo Mobile (futuro)
├── docs/         # Documentação técnica
└── README.md
```

A aplicação Web utilizará o padrão arquitetural MVC (Model-View-Controller), buscando manter a organização, separação de responsabilidades e facilidade de manutenção do código.

## 💡 Propósito

O Gratia Finance tem como propósito simplificar a gestão financeira pessoal, oferecendo ferramentas para acompanhar movimentações, organizar despesas, estabelecer metas e visualizar a evolução financeira.

A plataforma busca proporcionar mais controle, clareza e praticidade na tomada de decisões financeiras, reunindo informações importantes em um único ambiente.
